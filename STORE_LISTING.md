# Connect IQ Store listing — UV Index

## App name

UV Index

## Summary (short description)

A minimal watch face that puts the current UV index front and center — color-coded on the WHO scale, with an hourly UV forecast and the time.

## Description

UV Index is a clean, glanceable watch face built around one number: the current UV index at your location.

FEATURES

• Large UV index reading, color-coded on the WHO scale:
  green (low), yellow (moderate), orange (high), red (very high), violet (extreme)
• Risk label under the number so you always know what the value means
• 6-hour UV forecast bars along the bottom, each colored on the same scale, with the hour beneath
• Current time (respects your 12/24-hour setting)
• Data provenance line — where and when the reading was observed (e.g. "Paris · 23 min ago")
• Always-on display support: dimmed, mostly black layout with burn-in protection for AMOLED
• Pure black background for battery efficiency

PRIVACY & DATA

No accounts, no API keys, no network connections from the watch face itself. UV data comes from Garmin's built-in weather service, delivered through Garmin Connect on your paired phone. The Positioning permission is used only to show the name of the weather observation location and to determine local sunrise/sunset for night mode.

GOOD TO KNOW

• Right after installation the face may show "--" until Garmin Connect pushes weather data to the watch — make sure your watch is paired and synced.
• Weather (including UV) refreshes on Garmin's schedule, roughly every 20–60 minutes. A watch face cannot force a refresh.
• Forecast bars use Garmin's hourly forecast — hourly is the finest resolution the platform provides.

SUPPORTED DEVICES

Venu 4 (45 mm / 41 mm), Venu 3 / 3S, Forerunner 165 / 165 Music, Forerunner 265 / 265S, Forerunner 570 (47 mm / 42 mm), Forerunner 965, Forerunner 970, Vivoactive 5, Vivoactive 6, Fenix 8 (43 mm / 47 mm AMOLED), Fenix 8 Pro (47 mm), Fenix E.

## What's New

### v1.2

Night mode: when there's no meaningful UV now or in the coming hours, the face shows a crescent moon instead of a zero, tells you when UV returns ("UV from ~7:00"), and the forecast bars skip ahead to the next morning.

### v1.0 (first public release)

Initial public release. Current UV index with WHO color scale, 6-hour forecast bars, clock, observation location and staleness indicator, always-on display support.
